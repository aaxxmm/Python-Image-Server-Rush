# 🖼️ Сервер Картинок

Простой и надежный сервис для загрузки, хранения и раздачи изображений.

## ✨ Возможности

- **Загрузка изображений** - поддерживаются форматы JPG, PNG, GIF
- **Ограничение размера** - до 5 МБ на файл
- **Уникальные ссылки** - автоматическая генерация имен файлов
- **Быстрая раздача** - Nginx для статики
- **Долговременное хранение** - данные сохраняются между перезапусками
- **Подробное логирование** - все действия записываются в лог
- **Docker контейнеризация** - легкий запуск на любой системе

## 🚀 Быстрый старт

### Требования
- Docker 24.0+
- Docker Compose 2.20+

### Установка и запуск

1. Клонируйте репозиторий:
```bash
git clone https://github.com/your-repo/image-server.git
cd image-server
Запустите сервисы:

bash
docker-compose up --build
Откройте в браузере:

Главная страница: http://localhost:8080

Загрузка: http://localhost:8080/upload

Бэкенд напрямую: http://localhost:8000

📁 Структура проекта
text
image-server/
├── app.py                 # Основной бэкенд
├── requirements.txt       # Python зависимости
├── Dockerfile             # Docker образ бэкенда
├── docker-compose.yml     # Оркестрация контейнеров
├── nginx.conf             # Настройки Nginx
├── images/                # Volume для изображений
├── logs/                  # Volume для логов
└── static/                # Статические файлы

🔌 API

| Метод | Маршрут | Описание |
|-------|---------|----------|
| `GET` | `/` | Главная страница |
| `GET` | `/upload` | Форма загрузки |
| `POST` | `/upload` | Загрузка изображения |
| `GET` | `/images/<filename>` | Просмотр изображения (Nginx) |
| `GET` | `/images/help` | Инструкция по просмотру |

Пример загрузки через curl
bash
curl -X POST -F "image=@photo.jpg" http://localhost:8080/upload
Ответ:

json
{
  "success": true,
  "filename": "20250124_143022_a1b2c3d4.jpg",
  "url": "/images/20250124_143022_a1b2c3d4.jpg",
  "message": "Изображение успешно загружено"
}
📊 Логирование
Логи сохраняются в файл logs/app.log и содержат:

Время события

Тип события (INFO, WARNING, ERROR)

Детали операции

Пример:

text
[2025-01-24 14:00:00] INFO: Успех: изображение photo.jpg загружено
[2025-01-24 14:01:00] ERROR: Ошибка: неподдерживаемый формат файла (file.txt)
